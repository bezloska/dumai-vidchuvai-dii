# ДУМАЙ. ВІДЧУВАЙ. ДІЙ

Працююча браузерна гра: два текстуровані 3D-кубики одночасно підстрибують, обертаються зі сповільненням і приземляються. Верхні грані фізичних моделей визначають число та знак, які з'являються на оригінальній нижній плашці після завершення руху. На час кидка кнопку заблоковано.

## Відкрити гру

**Без сервера:** відкрийте готовий `play.html` у сучасному браузері з WebGL 2. Усі зображення, шрифт і код вбудовані в один файл. Він працює без Інтернету. Це згенерований файл для перегляду, а не публікація. Якщо браузер організації блокує адреси `file://`, відкрийте цей самий файл через локальний HTTP-сервер. У тестовому Chromium прямі `file://` заблоковані політикою середовища; автономний HTML перевіряється як єдиний документ через HTTP, після чого мережа вимикається для кидків.

**З вихідних файлів:** у корені репозиторію запустіть:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Відкрийте локальний сервер у браузері. Встановлення npm-залежностей для самого сайту не потрібне: Three.js та шрифт включено до `vendor/three/`. У GitHub Pages використовуватиметься цей самий `index.html` із відносними шляхами.

## Правила

- Перший кубик: шість граней із числами 1–6.
- Другий: три грані `+`, три `−`.
- Криптографічна випадкова вибірка з відхиленням modulo bias збережена.
- Однакова видима пара числа й знака не повторюється двічі поспіль. Перший кидок має 12 рівноймовірних результатів, кожний наступний — 11, крім попереднього.
- На верхній грані та в плашці завжди однаковий результат. Відмінювання: 1 крок, 2–4 кроки, 5–6 кроків.
- Історія скидається після перезавантаження сторінки.
- Враховано `prefers-reduced-motion`: результат відображається без стрибка й обертання.

## Оформлення

`background.png`, `cube.png`, `text panels.png` та підготовлені графічні файли плашок і фону в `assets/` не змінено на інтерактивному етапі. `assets/background-stage.svg` — той самий фон зі статичного макета, з раніше реконструйованими ділянками під кубиками та плашками.

Замість пласких PNG під час гри відображаються справжні WebGL-моделі: округлений золотий корпус, окремі мармурові грані та рельєфні золоті цифри/знаки. Мармурова фактура береться з ділянки без напису в оригінальному `cube.png`. Моделі відтворюють матеріали оригіналу; вони не є незмінним растром. Початкові PNG приховуються лише після готовності 3D, тому дублікати не відображаються. Якщо WebGL 2 недоступний, сторінка повідомляє про це й не імітує успішний кидок.

На смартфоні композиція показується повністю, а оригінальні кнопка та результат розташовані під нею у зручному для натискання й читання розмірі.

## Код

- `index.html`, `styles.css`: інтерактивна сторінка й адаптивне розташування.
- `dice3d.js`: моделі, текстури, світло, обертання, приземлення та перевірка фізичних верхніх граней.
- `game.js`: запуск, блокування кнопки, результат, доступність і обробка помилок.
- `random.js`: збережена логіка випадковості без однакових пар поспіль та відмінювання.
- `scripts/build-offline.cjs`: збирання автономного `play.html`.
- `tests/browser.cjs`: браузерні перевірки.

## Збирання автономного файлу та тести

Потрібні Node.js, npm та Chromium (у середовищі встановлено `/usr/bin/chromium`).

```sh
npm ci
npm run build:offline
npm test
```

За іншого розташування Chromium задайте `CHROMIUM_PATH`. Тест сам запускає тимчасовий локальний HTTP-сервер. Він перевіряє 12 послідовних кидків зі справжньою анімацією, відповідність орієнтації 3D-моделей плашці, всі 12 примусово заданих результатів, блокування повторного кліку, заборону повторів через різні фізичні грані одного знака, мобільні розміри та роботу автономного HTML із вимкненою мережею.

Three.js 0.180.0 постачається локально з MIT-ліцензією; Optimer — з ліцензією Magenta в `vendor/three/fonts/LICENSE`. npm потрібний лише для тестів і створення автономного HTML.

## Публікація

`.github/workflows/pages.yml` публікує поточну гру через GitHub Actions після push у `main` або ручного запуску workflow. У Settings → Pages джерело публікації має бути GitHub Actions. Pipeline включає HTML, CSS, усі модулі гри, вихідний `cube.png` для мармурової фактури, `assets/` та локальні бібліотеки `vendor/`; залежності від CDN немає.

Публічну адресу слід брати з успішного кроку Deploy. Сам push не підтверджує, що Pages увімкнено, deployment успішний або публічний сайт перевірено.
